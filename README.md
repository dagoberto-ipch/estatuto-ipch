## Aviso importante

Este es un **documento en revisión**, no el texto vigente. El original y el texto
oficial están en <https://ipch.cl/documentos.php>.

El texto de este sitio se obtuvo mediante **reconocimiento óptico (OCR)** a partir de
un PDF en el que las palabras están dibujadas como trazos vectoriales, sin capa de
texto. Por eso **puede contener errores de transcripción**. Si necesitas citar un
artículo, contrasta con el original.

## Cómo se hizo

El PDF original no permite copiar texto (`/BaseFont 0`, cero operadores de texto), así
que el contenido se recuperó con el motor de OCR de Windows y se procesó en un
segmentador que detecta los artículos **por su secuencia de ordinales** (del 1 al 295,
sin saltos), en lugar de heurísticas de puntuación. Eso permite distinguir los artículos
reales de las referencias cruzadas del tipo «conforme al Artículo nueve de la ley».

El sitio es un único archivo HTML: el símbolo va incrustado y no depende de fuentes
externas ni de conexión.

## Publicar cambios

El contenido vive en `docs/index.html`, que es un archivo generado. Para actualizarlo
hay que regenerarlo con las herramientas del repositorio de trabajo y volver a subirlo;
este repositorio solo aloja el resultado.
